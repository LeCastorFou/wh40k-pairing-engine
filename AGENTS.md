# Agent Instructions

## How To Use upkeep

- Every user-visible feature, workflow, route, permission, data field, integration, or pairing behavior change must include a review of `templates/how_to_use.html`.
- If the change affects how someone uses the tool, update the dedicated How To Use page in the same change.
- If the How To Use page does not need changes, mention that explicitly in the final response and explain why.
- Keep the index page focused on the title and functionality entry points; detailed usage documentation belongs on `/how-to-use`.
